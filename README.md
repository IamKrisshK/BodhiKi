# 🌿 Bodhi-ki

**A Mind Focus & Rejuvenation Platform**

Bodhi-ki is a web-based application designed to help users balance **productivity, mindfulness, and social interaction** in one unified platform. It combines features like study session tracking, meditation modes, social posting, and analytics to promote healthier digital habits.

---

## 🚀 Features

* 🔐 **User Authentication**
  Secure login and registration system

* 🏠 **Dashboard (Social Feed)**
  Create posts (text + media) and interact using likes

* 🌱 **Zen Garden**
  Relaxation modes:

  * Quick Reset
  * Vipassana
  * Peak Focus
  * Deep Rest

  - Emoji-based feedback system

* 📚 **Study Module**

  * Study session creation
  * Modes: Pomodoro, Deep Work, Hardcore
  * Concentration levels: Low, Medium, High
  * Topic tracking

* 📊 **Analytics**

  * Focus time, study time, feed time
  * Sessions tracking
  * Activity trend line chart
  * Category breakdown (pie chart)

* ⚙️ **Settings**

  * Edit profile (username, email)
  * Secure logout

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/IamKrisshK/team8.Bodhi-ki
cd team8.Bodhi-ki
```

### 2. Install dependencies

```bash
# frontend
cd frontend
npm install

# backend
cd ../backend
npm install
```

### 3. Run the application

```bash
# backend
npm start

# frontend
cd ../frontend
npm start
```
